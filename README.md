# Bank Loan Default Risk Analysis

## Project Overview
This project analyzes bank loan data to understand loan default patterns and identify factors associated with borrower risk. An interactive Power BI dashboard presents key metrics and insights to support data-driven decision-making.

## Business Objectives
- Analyze loan default and non-default cases.
- Calculate the loan default rate.
- Explore default patterns across borrower and loan characteristics.
- Identify risk patterns by income, debt-to-income ratio (DTI), credit score, loan amount, and region.
- Present findings through clear visualizations.

## Tools Used
- **Microsoft Excel:** Data review and preparation
- **Power BI:** Dashboard development and data visualization
- **DAX:** Measures and KPI calculations
- **SQL / Python:** Include these only if they were actually used in this project.

## Dataset
The dataset contains loan and borrower information, including loan amount, credit score, income, age, debt-to-income ratio, property value, region, and loan default status.

## Key Metrics
- **Total Loans:** 148,670
- **Defaulted Loans:** 36,639
- **Non-Defaulted Loans:** 112,031
- **Default Rate:** 24.64%

## Dashboard Analysis
The dashboard explores:
- Default rate by income group
- Default rate by DTI group
- Default rate by loan amount group
- Default rate by credit score group
- Default rate by region
- Overall loan default status

Interactive slicers allow users to explore the data by region, loan purpose, age group, and loan limit.

## Conclusion
This project demonstrates how loan data can be analyzed and visualized to understand default patterns and support risk assessment. The dashboard helps users explore borrower and loan characteristics associated with default outcomes.
